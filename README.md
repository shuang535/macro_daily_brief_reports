## 閱讀方式

Daily 聚焦最近交易日與下次開盤風險，Weekly 彙整整週判斷與下週驗證。先讀 Quick Take 與 Top News，再依需要查閱行情、個股及參考資料；點選折疊區可展開完整表格。新聞與日程以臺北時間呈現，行情保留各市場交易日。每份報告皆列明資料截止日與計算口徑。

同一日或同一週的修訂更新原檔，歷次版本保留在 Git 提交紀錄。公開儲存庫保存報告與索引，報導採摘要並附來源連結。
