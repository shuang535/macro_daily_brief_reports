## 閱讀方式

Daily 聚焦最近交易日與下次開盤風險，Weekly 分析整週路徑、判斷變化與下週驗證。先看主要指數表與 Market／Weekly Commentary，再讀其他重要消息及各市場短解盤；段落分類方便跳讀，Note 說明相關個股與曝險。完整行情、個股及參考資料直接展開，可由頁首連結前往各節。新聞與日程以臺北時間呈現，行情保留各市場交易日。每份報告皆列明資料截止日與計算口徑。

10/12 臺美與中國日報於 10/13 修訂文字並同步 PDF：統一 YoY／QoQ／MoM 與 +／- 格式，精簡重複但書與個股說明；沿用原行情、統計標記、來源與新聞截止。

同一日或同一週的修訂更新日期子目錄中的同名檔，歷次版本保留在 Git 提交紀錄。2026-10-13 整理前的平面路徑與 `china/` 報告凍結為當時已發布版本，以保留既有外部連結；最新內容以本索引的日期子目錄為準，舊路徑不再接收新修訂。公開儲存庫保存報告與索引，報導採摘要並附來源連結。
